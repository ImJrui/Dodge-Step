# 原创手绘标题候选

三个字的主要笔画均独立绘制为路径轮廓，没有调用或转换任何字体字形。候选保留橙黄色调和无底部文字的布局。

- A：破风疾闪（刀锋笔画 · 断笔飞屑 · 速度拖尾）。
- B：灵魂焰字（弯曲火舌 · 灵魂回旋 · 熔金光泽）。
- C：暗影刻印（尖角轮廓 · 刻痕裂口 · 符文碎片）。

`*_outlines.svg` 为手绘基础轮廓，`*_lettering.png` 为含高光、断笔及装饰的完整字标，`*_overlay.png` 为适配动图的透明图层，`*_scene.png` 为 960 × 960 场景预览。当前 GIF 已应用 A「破风疾闪」方案，B、C 保留为候选预览。
